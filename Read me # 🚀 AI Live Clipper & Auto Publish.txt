# 🚀 AI Live Clipper & Auto Publisher

**Real-Time AI-Powered Live Streaming, Automatic Highlight Detection, Video Clipping & Social Media Publishing**

## 1. Project Overview

AI Live Clipper is a Python-based application that monitors live video streams, detects interesting moments using Google Gemini AI, automatically creates vertical short-form videos, and publishes approved clips to multiple social media platforms.

### Supported Platforms

- YouTube Shorts
- Instagram Reels
- Facebook Reels
- TikTok

### Main Features

- Real-time live stream ingestion using RTMP.
- AI-powered highlight and viral moment detection.
- Automatic 30–60 second clip generation.
- Custom topic-based highlight detection.
- Dynamic 9:16 video cropping.
- Automatic subtitles and captions.
- AI-generated hooks, titles, descriptions, and hashtags.
- Optional background music removal using Demucs.
- Automated social media publishing.
- Publishing status and error tracking.
- Command-line configuration.

## 7. AI Highlight Detection

Gemini will analyze video segments and identify:

- Funny moments.
- Important conversations.
- Unexpected reactions.
- Gaming highlights.
- Interesting discussions.
- Strong opening hooks.

Each detected highlight should return structured JSON:

```json
{
  "start": 125,
  "end": 170,
  "score": 95,
  "hook": "You Won't Believe This!",
  "position": "center",
  "reason": "Unexpected funny moment",
  "title": "Crazy Live Stream Moment",
  "hashtags": [
    "#shorts",
    "#gaming",
    "#viral"
  ]
}
```

Use Pydantic validation before sending the clip to FFmpeg.

## 8. Live Stream Processing

The application should:

1. Receive an incoming RTMP stream.
2. Maintain a rolling buffer.
3. Analyze recent video and audio segments.
4. Identify interesting moments.
5. Retrieve the required pre-event and post-event footage.
6. Generate a standalone clip.
7. Avoid duplicate highlights.
8. Send completed clips to the publishing queue.

Use configurable analysis intervals to control API costs.

Do not send every frame individually to Gemini.

## 10. Automatic Publishing

Each publishing integration must use the platform's official API.

### YouTube

Use YouTube Data API v3 and OAuth 2.0.

### Instagram

Use Instagram Graph API with an eligible Professional account.

### Facebook

Use Facebook Graph API with appropriate Page permissions.

### TikTok

Use TikTok Content Posting API with approved publishing permissions.

Publishing must include:

- OAuth authentication.
- Video upload.
- Caption and description.
- Hashtags.
- Publishing status.
- Error handling.
- Retry management.

Never assume an API call succeeded until the platform confirms publication.

## 11. Development Commands

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python main.py
```

Start optional FastAPI service:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Example local video test:

```bash
python main.py --input sample.mp4 --clips 5
```

Example topic-based processing:

```bash
python main.py \
    --input sample.mp4 \
    --clips 5 \
    --topic "funny moments"
```

Example live processing:

```bash
python main.py \
    --source rtmp://localhost:1935/live/stream \
    --clips 5 \
    --auto-publish
```

These commands define the intended interface; implement the corresponding argument handlers before using them.

## 13. Deployment Notes

GitHub Codespaces is intended for development and testing.

For continuous production live processing, deploy the application to a dedicated server with sufficient CPU, RAM, storage, and network bandwidth.

Recommended production components:

- Linux VPS.
- MediaMTX.
- Python application.
- FFmpeg.
- Persistent storage.
- Process supervisor.
- Secure credential storage.

A persistent server is necessary because Codespaces can stop or shut down when inactive.

## 14. Important Limitations

- Social platform publishing requires account eligibility and API approval.
- TikTok public publishing may require an app audit.
- Gemini analysis has usage-based API charges.
- Copyright compliance must be checked separately.
- AI-generated highlights are not guaranteed to be viral.
- Demucs cannot guarantee complete removal of copyrighted music.
- Real-time processing has unavoidable analysis and publishing latency.
